# Recall check sheet (for a human reviewer)

**Purpose.** The expected-edge list `backend/tests/expected_edges.yml` was written by the tool's author, and the recall measured against it is a measure on **synthetic data**. This sheet lets someone else check a random sample of it against the source.

**How it was made.** 15 rows chosen at random (Python `random.Random(20261111)`): 12 of the 82 expected edges and 3 of the 7 "should not exist" guards. Each row gives the location the list cites and the source text read from disk (the pinned copy in `backend/tests/fixtures/sample/samples/`). **Nothing in the three right-hand columns has been filled in.**

**How to use it.** For an *expected edge*: does the cited code really create that relationship (**real?**), and is the target the right one (**right target?**). For a *should-not-exist guard*: the tool must NOT report the relationship; answer **real?** with whether you believe such a relationship genuinely exists in the code (the expected answer is no), and write in **notes** if the cited code makes you doubt the guard.
